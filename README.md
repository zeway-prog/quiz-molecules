Jeu simple pour afficher aléatoirement des noms de molécules (adultes / enfants).

- Bouton Début : affiche une molécule aléatoire et indique si elle vient de la liste Adulte ou Enfant.
- Bouton Suivant : supprime définitivement la molécule affichée puis affiche une nouvelle molécule aléatoire provenant des noms restants.
- Quand il ne reste qu'une molécule, le bouton Suivant est désactivé et le bouton Reset est activé.
- Bouton Reset : restaure les listes initiales.

Ouvrir `index.html` dans le navigateur pour jouer.
